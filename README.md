# The Forecheck Index

## Background

The 2022-2023 Boston Bruins had the best regular season record in NHL history (65-12-5) before tragically blowing a 3-1 lead in the first round of the playoffs to the Florida Panthers. Like all other Bruins fans, I was distraught, but took some solace in the resulting dominance of the Panthers following this upset: a run to the Cup Final followed by back-to-back championships. Watching this team play, it is impossible to ignore the seeming effectiveness and suffocation of their forecheck. This project aims to uncover whether this eye-test is evident numerically, gauge the Panthers' place among other recent great teams, and determine whether forechecking can be used as an effective metric to predict team success.
